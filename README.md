# .github — Standard-Community-Dateien

**English summary:** This repository holds the default community health files
(code of conduct, contributing guide, security policy, support notes, issue and
pull request templates) for all repositories of
[marcohost33-maker](https://github.com/marcohost33-maker). A repository that
ships its own file of the same name uses its own file instead.

Absender: Coworker Research (Coworkerz).

## Was hier liegt

| Datei | Zweck |
|---|---|
| [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) | Verhaltenskodex (Contributor Covenant 2.1) |
| [CONTRIBUTING.md](CONTRIBUTING.md) | Wie Beiträge ablaufen |
| [SECURITY.md](SECURITY.md) | Wie Sicherheitslücken vertraulich gemeldet werden |
| [SUPPORT.md](SUPPORT.md) | Wo Fragen hingehören und was man erwarten kann |
| [.github/PULL_REQUEST_TEMPLATE.md](.github/PULL_REQUEST_TEMPLATE.md) | Vorlage für Pull Requests |
| [.github/ISSUE_TEMPLATE/](.github/ISSUE_TEMPLATE/) | Formulare für Bug-Reports und Feature-Wünsche |

## Wie das wirkt

GitHub verwendet diese Dateien für jedes Repository des Kontos, das keine eigene
Datei mit demselben Namen hat. Hat ein Repository eine eigene Datei (zum
Beispiel ein eigenes `SECURITY.md`), gilt diese. Lizenzen werden nicht vererbt;
jedes Repository trägt seine eigene `LICENSE`.

Quelle: GitHub Docs, [Creating a default community health file](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file).
