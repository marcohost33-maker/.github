# Support

**English summary:** These repositories contain research and engineering code
from a small team. There is no guaranteed support. Questions and bug reports are
welcome as issues in the affected repository; security issues go to that
repository's Security tab.

## Was man erwarten kann

Die Repositories sind Forschungs- und Werkstatt-Code eines kleinen Teams. Es gibt
keine Support-Garantie und keine zugesicherten Antwortzeiten, ausser ein
Repository nennt in seinem eigenen `SECURITY.md` andere.

## Wohin mit Fragen

- **Fragen, Fehler, Wünsche:** als Issue im betroffenen Repository. Die
  Formulare für Bug-Reports und Feature-Wünsche helfen, das Nötige anzugeben.
- **Sicherheitslücken:** nicht als Issue, sondern vertraulich, siehe
  [SECURITY.md](SECURITY.md).
- **Verhalten in der Community:** siehe
  [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

Bitte keine Secrets, Tokens oder personenbezogenen Daten in Issues einfügen.
